# mypro — 業務サポート用ナレッジベース

自分の業務内容を Claude に把握させ、PM兼アシスタントとして日々の業務を支援してもらうためのリポジトリ。

## 構成
| パス | 内容 |
|---|---|
| `CLAUDE.md` | Claude への指示(毎セッション読み込まれる) |
| `profile/profile.md` | 所属・役割・関係者・使用ツール |
| `work/duties.md` | 業務一覧(定常業務・プロジェクト業務の棚卸し) |
| `work/repositories.md` | 担当リポジトリ一覧(概要・技術・状況) |
| `work/hearing.md` | Claude からのヒアリング項目(未確認事項) |
| `work/domain-strategy.md` | ドメイン・ブランド方針(案) |
| `work/milestones.md` | 全案件のマイルストーン・期限 |
| `tasks/tasks.md` | 進行中・予定のタスク(優先度・期限・状態) |
| `projects/<案件>.md` | 案件ごとの管理(納期・現状評価・リスク・計画) |
| `log/YYYY-MM-DD.md` | 作業ログ・決定事項・次のアクション |

## 使い方
1. 業務について思いつくまま Claude に話す(箇条書き・雑なメモで可)。
2. Claude が各ファイルに整理して反映する。
3. 日々「今日やること」「この件どうする?」と相談すると、蓄積内容を踏まえて支援する。
