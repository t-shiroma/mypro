# RYU'S Apps 勤怠(ryus-apps)

> 最終更新: 2026-11-20 / ユーザー提供情報 + リポジトリ調査

## 概要
| 項目 | 内容 |
|---|---|
| 種別 | 自社SaaS(**勤怠SaaSとして開発中**) |
| 位置づけ | RYU'S Apps(SaaS シリーズ)の第1弾。公開ドメイン `ryus-apps.jp` |
| 構成 | portal(LP・料金・申込)/ accounts(共通ログイン)/ kintai(勤怠)/ admin(運営) |
| 技術 | React + Hono + Prisma + PostgreSQL(RLS によるテナント分離) |
| 方針 | フェーズ1は、社内の WorkApp の勤怠を**マルチテナント化して移植**(新機能は足さない) |
| 開発 | 2026-11-05〜11-10 に集中開発(約120コミット)。その後は停止。説明書(manual)も作成済み |

## PM 観点の気づき
- **勤怠の実装が3か所にある**:work-app(社内・運用中)、ryus-apps(SaaS)、tsumiki(保育園向け勤怠・要件とプロトタイプ)。保守の重複を避けるため、tsumiki を ryus-apps の業種別プラン(保育園向け)にする、WorkApp を将来 ryus-apps に寄せる、などの整理を検討したい。
- 未決定事項の多く(決済・規約・配置先・料金)は**宿泊税 SaaS で先に決めたものを流用できる**(Stripe、KAGOYA + Cloudflare、規約の雛形)。
- 2027年2月までは宿泊税 SaaS と facility-booking が優先と思われる。ryus-apps の公開目標時期を決め、それまでに未決定事項を順に決める計画が現実的。
