# 沖縄宿泊税 SaaS(okinawa-stay-manager-v2)

> 最終更新: 2026-11-20

## 概要
| 項目 | 内容 |
|---|---|
| 種別 | 自社SaaS |
| 対象 | 沖縄県宿泊税の特別徴収義務者(ホテル・民泊など) |
| 内容 | 宿泊実績の登録 → 県税・市町村税の自動計算 → 月計表・帳簿・申告データの作成。Airbnb 取込、Stripe 課金、公開マップ(おきなわ宿マップ)、領収書のモバイル印刷 |
| 技術 | React + Hono + PostgreSQL(RLS)。本番は KAGOYA VPS + Cloudflare の予定 |
| **期限** | **2027年2月までに稼働**(宿泊税の施行は 2027-02-01) |
| 開発 | ユーザー本人が直接コミット(11/2 初期コミット〜11/18 まで 40 件) |

## 期限の意味
- 2/1 の宿泊分から課税されるため、**利用者が 2/1 より前に登録・初期設定(施設・料金・税設定)を終えている必要**がある。実質の稼働目標は 1 月中旬と考えるのが安全。
- 最初の申告は 2 月分(3 月末が期限の見込み。3か月特例の施設は後ろ倒し)。申告書出力は 3 月までに完成していればよい。
